# @season179/pi-delegate (RETIRED)

**Failed experiment — retired 2026-07-28.** Never published, not
installed. Do not load this extension or build on its code.

It gave pi a `delegate` tool: hand well-scoped briefs to a cheap worker
model in a headless `pi` subprocess. Superseded by visible, managed delegation through the Herdr workflow: Herdr
owns panes, agents, lifecycle, and synchronous dispatch, while pi-herdr adds
the non-blocking watch/wake bridge. See the repository
[delegation tombstone](../../docs/DELEGATE.md) and
[`packages/pi-herdr`](../pi-herdr).
