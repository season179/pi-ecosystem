# @season179/pi-moa (RETIRED)

**Retired 2026-07-28 — superseded by [`@season179/pi-buddy`](../pi-buddy).**

This experiment registered a synthetic `moa/*` provider that gathered several reference-model responses before an aggregator answered each turn. It was retired after Buddy's cheaper, tool-enabled consultation and automatic-review approach replaced it.

Do not install, build on, or treat this package as current guidance. It is not available on npm; the source remains only as a historical record and can be recovered from git history.

Buddy is not a drop-in `moa/*` provider replacement. It is a Pi extension that supplies requested consultations and automatic reviews while the main model remains responsible for the answer and actions.

See the [retired design record](./docs/DESIGN.md) for historical architecture and findings.
