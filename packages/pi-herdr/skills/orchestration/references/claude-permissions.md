# Claude permission prompts

Read when a Claude worker shows a permission prompt, or when auto mode is unavailable, denied, or paused for approval.

For a worker you are authorized to control, you may select its visible **"Yes, and switch to auto mode"** option without asking the user again, provided the pending action is within the authorized scope and no user or environment restriction forbids auto. That option also approves the pending action: inspect it first. Read the current prompt and select by its label, not a remembered option number; verify auto is active and rearm the watch. Do not change global settings or unrelated workers.

If auto is unavailable, a classifier denial occurs, or auto pauses for approval, inspect the blocker; do not evade it by changing modes or blindly approving. Ask the user when the action needs new authority or a restriction requires their approval.
